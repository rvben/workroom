# Workroom 0.1.0 — public preview

A local workspace that brings Jira tickets, GitLab merge requests, ServiceNow incidents, related Outlook messages and coding-agent activity into one attention inbox.

## Included

- Guided CLI installation, sign-in and source verification, with project, incident and mail-folder filters.
- An attention inbox, linked context, source freshness, personal and team MR views, private notes and snoozes.
- Local branch/worktree creation from Jira issues, reviewable proposals and a durable work timeline.
- Explicit agent selection; generic Codex, Claude Code and Cline reporting examples, plus a managed Claude terminal adapter with conversation resume.
- MIT-licensed source and a release archive with the built frontend. Dependencies install from the committed npm lockfile.

## Install

Download `workroom-0.1.0.tar.gz` and `SHA256SUMS` from this release. On macOS:

```sh
shasum -a 256 -c SHA256SUMS
tar -xzf workroom-0.1.0.tar.gz
cd workroom-0.1.0
npm ci --include=dev
npm start
```

On Linux, use `sha256sum -c SHA256SUMS`. Open http://127.0.0.1:4310 and explore the demo or follow guided setup. Requires Node.js 24 or newer, npm and Git on macOS or Linux, including WSL. CLIs and agents are installed and authenticated separately. The generic GitHub source archives require `npm run build` before starting.

## Preview boundaries

This is a single-user local application. It is not a hosted team service or a complete Jira replacement. Collections are bounded; Outlook relationships are per-message and do not guarantee a complete conversation. Codex and Cline have the generic reporting path, without native capture adapters. Only the latest preview is maintained.

Live Jira access has been exercised. GitLab, ServiceNow and Outlook collection flows have automated fixture coverage and still need authenticated end-to-end trials. The managed Claude adapter has a limited live CLI smoke test; interactive work-machine behaviour and live MR publication need further trials. CI and release checks use synthetic data and do not establish production compatibility with every service configuration.

No credentials, local settings, databases, agent transcripts, worktrees, design reports or screenshots are included. See [Security](https://github.com/rvben/workroom/blob/v0.1.0/SECURITY.md) before sharing diagnostics and the [onboarding guide](https://github.com/rvben/workroom/blob/v0.1.0/docs/onboarding.md) for connection recovery.
